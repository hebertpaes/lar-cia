No seu Mac

1. OpenClaw — abrir e apontar para a VM

Rode o OpenClaw no Mac e conecte na VM por SSH. Substitua IP_DA_VM e azureuser.

# abrir sessão SSH na VM (guarde a chave em ~/.ssh)
ssh azureuser@IP_DA_VM

Prompt p/ o OpenClaw — cole como instrução:

Conecte na VM azureuser@IP_DA_VM por SSH, entre em /opt/lar-cia/infra e
rode "bash setup.sh". Depois me mostre a saída de "docker compose ps".
Na VM (uma vez)

2. Subir os 3 portais (Ghost + MySQL + Caddy)

# enviar a pasta infra/ para a VM (do seu Mac, na raiz do repo)
scp -r infra azureuser@IP_DA_VM:/opt/lar-cia/infra

# na VM: configurar segredos e subir
cd /opt/lar-cia/infra
cp .env.example .env        # edite as senhas (nano .env)
bash setup.sh

A Caddy emite o HTTPS sozinha quando os DNS já apontam para o IP da VM. Depois, abra https://<dominio>/ghost em cada portal e suba o tema (.zip) em Design → Change theme.

GitHub

3. Deploy automático (CI)

Cadastre os secrets em Settings → Secrets and variables → Actions: VM_HOST, VM_USER, VM_SSH_KEY. A cada push na main (ou manual) o workflow gera os .zip, envia para a VM e sobe a stack.

# gerar a chave de deploy (no Mac) e autorizar na VM
ssh-keygen -t ed25519 -f ~/.ssh/lar-cia-deploy -N ""
ssh-copy-id -i ~/.ssh/lar-cia-deploy.pub azureuser@IP_DA_VM
# o CONTEÚDO de ~/.ssh/lar-cia-deploy vai no secret VM_SSH_KEY
cat ~/.ssh/lar-cia-deploy
Cloudflare

4. CDN (carregamento rápido)

Adicione cada domínio no Cloudflare, troque os nameservers no registrador e ligue a nuvem laranja. Detalhes em infra/CLOUDFLARE.md. Ajustes: SSL Full (strict), Brotli, Auto Minify, e nunca cachear /ghost/* nem /members/*.

Notícias

5. Automação (coleta + IA + publica)

Já roda de hora em hora no GitHub Actions. Disparo manual:

# publicar agora (precisa dos secrets *_ADMIN_KEY no repositório)
gh workflow run publicar.yml -f dry_run=false
Operação

6. Backup e manutenção

# backup dos bancos (na VM)
cd /opt/lar-cia/infra
for d in hojemt odiapolitico pacunews; do
  docker compose exec -T db mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" ghost_$d > backup_$d_$(date +%F).sql
done

# atualizar Ghost/MySQL/Caddy
docker compose pull && docker compose up -d
